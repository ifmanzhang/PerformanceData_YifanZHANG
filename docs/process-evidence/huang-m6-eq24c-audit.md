# Huang M6 Eq.24c Audit Summary

Original local source:

`artifacts/targets/soap-film-m6-eq24c-fullsize-comparison.md`

## Purpose

This local audit recorded a full-size Huang-style reproduction attempt using an Eq.24b / Eq.24c-consistent eta source.

## Finding

The run was numerically stable, but the resulting morphology was still too smooth and broad for the final performance image. This suggested that the remaining problem was not only one numerical bug. The visual target also depended on morphology, scene setup, render character, droplet behaviour and production suitability.

## Evidence Value

This explains why the project did not keep trying to make the Huang reproduction itself become the final artwork. The work remained valuable because it informed the later SoapBubble physics direction, cache thinking and performance optimisation, but the final submission prioritised a pipeline that could deliver denser droplets, richer optical detail and stable final video output.
