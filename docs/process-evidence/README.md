# Cleaned Process Evidence Archive

This folder contains lightweight summaries of selected evidence from the local process workspace:

`C:\Users\Ifmanzhang\Documents\performance data`

The full local workspace is not suitable to upload as a whole. It contains large render outputs, build artefacts, raw experiments, temporary caches and some early notes with encoding problems. These summaries keep the useful evidence in a small, readable form.

## Scope

The documents here support the final project narrative:

- a realtime visual route was tested before the final offline render pipeline;
- true physics parameter changes were expensive and required delayed rendering;
- cache interpolation was evaluated but not treated as physically equivalent to recomputation;
- the Huang-style reproduction was useful but did not become the final visual method;
- early PLUX/EDA/five-indicator work informed the project but was not used as the final control layer.
